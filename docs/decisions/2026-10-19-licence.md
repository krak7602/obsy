# MIT licence

## Context

obsy should be easy for others to adopt. Nearby projects use MIT, Apache-2.0, GPL-3.0, and PolyForm Strict.

## Decision

obsy is MIT. Ideas come from public documentation and permissively licensed projects only. Remotely Save's current sync engine (PolyForm Strict) and GPL code are not copied.

The working rules are on [Clean-room licensing](../concepts/clean-room-licensing.md).

## Consequences

- Contributors must not read or copy the code listed as forbidden on the clean-room page.
- Reused permissive code needs its notice in `THIRD_PARTY_NOTICES.md`.
