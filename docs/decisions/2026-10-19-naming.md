# Naming

## Context

The working name was "obsync". That name is already taken by an MIT project with a similar stack, "Cloudflare Workers + Obsidian Plugin" ([less1001/obsync](https://github.com/less1001/obsync)). On npm, the bare `obsy` name belongs to an unrelated package.

## Decision

- The project is **obsy**.
- npm packages use the `@obsy` scope.
- The Obsidian plugin ID is `obsy`.
- The community directory display name is "Obsy - Sync Vaults". It is unique, follows the "Name - What it does" pattern many listed plugins use, and contains "sync" and "vault" for search.

## Consequences

- Package names in the [architecture](../architecture.md) use `@obsy/…`.
